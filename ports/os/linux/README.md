# OS port: linux

This directory contains target-specific build, ABI and packaging work for `linux`.  See `config/targets.json` for status.

## RISC-V 64

`riscv64` is an RV64-only research target. Native RV64 systems may use this OS wrapper directly; cross-builds can use `build/arch/riscv64-linux.sh`. RV32 is not supported.
