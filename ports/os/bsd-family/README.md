# OS port: bsd-family

This directory contains target-specific build, ABI and packaging work for `bsd-family`.  See `config/targets.json` for status.

## RISC-V 64

The generic BSD matrix includes an RV64-only `riscv64` research entry. Verify each BSD independently; do not infer support for one BSD from another, and never create an RV32 WaifuCAD target.
