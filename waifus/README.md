# Waifus

`nightcore.png` in this working package was supplied by the user through the GUI reference image and is the default GTK4 ribbon artwork.

Additional user-supplied images listed in `manifest.json` may be copied into this directory. The GTK4 front-end looks for `nightcore.png`, then `sakura_riddle.png`, then `luotianyi.png`. Missing optional artwork does not prevent the CAD application from launching; a project-owned SVG placeholder is used instead.
